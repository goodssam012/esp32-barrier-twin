# 🚧 손동작 차단기 디지털 트윈 (Wi-Fi · 서보 1개)

**손바닥을 기울인 각도만큼 차단바가 움직입니다** (또는 주먹 = 올림 / 손 펴기 = 내림). PC 웹캠으로 손을 인식하고, Wi-Fi(WebSocket)로
ESP32-S3에 명령을 보냅니다. ESP32는 실제 서보 위치를 다시 보고하고, 웹의 3D 가상 차단기가
그 위치를 그대로 따라 움직입니다(디지털 트윈). 가상 공간에서는 자동차가 차단기가 열릴 때만 지나갑니다.

**🌐 웹 버전:** https://goodssam012.github.io/esp32-barrier-twin/ (Chrome/Edge)

| 기능 | 웹 버전 | PC 실행 (`start.bat`) |
|---|---|---|
| 카메라 손 인식 + 3D 트윈 시뮬레이션 | ✅ | ✅ |
| ⚙ 펌웨어 업로드(USB), Wi-Fi 검색·설정 | ✅ 미리 빌드된 펌웨어 | ✅ 소스 컴파일도 가능 |
| Wi-Fi로 ESP32 실시간 제어 | ❌ 브라우저가 https 페이지의 `ws://` 접속을 차단 | ✅ |

```
웹캠 ─▶ MediaPipe 손 관절 ─▶ 주먹 정도(0~100%) ─▶ 펼침/주먹 판정 ─▶ "A,90"  ──Wi-Fi──▶ ESP32-S3 ─▶ 서보
                                                                   3D 가상 차단기 ◀── "POS,45.0,90.0" ◀──┘
```

| 파일 | 내용 |
|---|---|
| `firmware/esp32s3_barrier/esp32s3_barrier.ino` | ESP32-S3 스케치 (Wi-Fi + WebSocket 서버, 포트 81, USB 설정 명령) |
| `server.py` | 로컬 웹 서버 + 소스 컴파일 API (`start.bat`이 실행) |
| `setup_arduino.bat` | 컴파일용 arduino-cli 설치 (한 번만) |
| `web/barrier.html` | 카메라 인식 + 3D 차단기 + Wi-Fi 통신 + ⚙ 환경설정(펌웨어 업로드, Wi-Fi 검색/접속) |

### 배선
- 서보 신호선 → **GPIO 4**, 서보 전원 → 5V(외부 전원 권장), GND → ESP32 GND와 공통

### 처음 한 번: ⚙ 환경설정으로 보드 세팅 (Arduino IDE 불필요)
웹페이지 오른쪽 위 **⚙** 아이콘을 누르면 USB로 ESP32-S3를 세팅할 수 있습니다.

| 단계 | 내용 |
|---|---|
| 0. USB 연결 | **USB 포트 선택** → ESP32-S3 포트 선택 (보드 종류에 맞춰 USB 방식이 자동 선택됨) |
| ① 펌웨어 업로드 | 소스 `firmware/esp32s3_barrier` 선택 → **업로드** (PC에서 컴파일 후 브라우저가 바로 기록) |
| ② Wi-Fi 설정 | **Wi-Fi 검색** → 목록에서 선택 → 비밀번호 입력 → **접속 및 저장** |
| 완료 | **이 주소로 차단기 연결 ▶** 을 누르면 USB를 놓고 Wi-Fi로 연결됩니다 |

- Wi-Fi 정보는 소스에 적지 않고 **보드 내부(NVS)에 저장**됩니다. 전원을 다시 켜도 자동 접속합니다.
- 소스(.ino)를 컴파일하려면 PC에 **arduino-cli**가 필요합니다. `setup_arduino.bat`을 한 번 실행하면
  arduino-cli, ESP32 보드 패키지, 라이브러리(WebSockets)를 설치합니다(수백 MB).
- arduino-cli 없이도 Arduino IDE에서 `스케치 > 컴파일된 바이너리 내보내기`로 만든 **`.merged.bin`** 을
  "직접 선택: .bin 파일"로 골라 업로드할 수 있습니다(주소 0x0).
- 업로드 연결이 안 되면 보드의 **BOOT** 버튼을 누른 채 **RST**를 눌렀다 떼고 다시 시도하세요.

### 실행
1. PC를 ESP32와 **같은 Wi-Fi(공유기)** 에 연결
2. `start.bat` 실행 → `http://localhost:8000/barrier.html`이 열림 (Chrome/Edge)
3. **카메라 시작** → 주소칸에 `barrier.local` 또는 보드 IP 입력 → **ESP32 연결** (⚙에서 연결했다면 생략)
4. **제어 방식**을 고르고 보정합니다.

| 제어 방식 | 동작 | 보정 |
|---|---|---|
| **손바닥 각도 (비례 제어, 기본)** | 손이 차단바 역할을 합니다. 손가락이 옆을 향하면(손을 눕히면) 0° 내림, 위를 향하면(손을 세우면) 90° 올림, 그 사이 각도는 그만큼 열림 | 손을 눕히고 **①**, 손을 세우고 **②** |
| **주먹/펴기 (2단 제어)** | 주먹 ✊ → 올림 / 손 펴기 ✋ → 내림 | 손을 펴고 **①**, 주먹을 쥐고 **②** |

- 손바닥 각도는 손목 → 중지 뿌리 방향으로 계산하며, 카메라 화면에 노란 선으로 표시됩니다. 왼손/오른손, 손가락이 왼쪽/오른쪽 어느 쪽을 향해도 됩니다.
- 비례 제어에서 차단바가 손을 늦게 따라오면 **이동 속도**를 올리세요(예: 240°/s).
- **내림/올림 각도**: 서보 장착 방향에 맞게 조절 (예: 반대로 돌면 내림 90°, 올림 0°)
- **판정 유지시간**(2단 제어 전용): 동작을 이 시간 이상 유지해야 바뀜 (오동작 방지)
- 손이 화면에서 사라지거나 Wi-Fi가 끊기면 차단기는 **마지막 위치를 유지**하고, 웹은 2초마다 자동 재접속합니다.
- 상단 `트윈: 실물 위치 동기화`가 초록색이면 가상 차단기가 ESP32의 실제 위치를 표시하는 중입니다.
  미연결 시에는 `시뮬레이션`으로 동작합니다.

### 문제 해결
- **`barrier.local`로 연결 안 됨** → IP 주소를 직접 입력
- **IP로도 안 됨** → PC와 ESP32가 같은 공유기인지, 공유기의 "AP 격리/게스트 네트워크" 기능이 꺼져 있는지 확인
- **Wi-Fi 연결 실패** → 5GHz 전용 SSID가 아닌지, SSID/비밀번호 확인

# (이전 버전) 손가락 5개 → ESP32-S3 서보 디지털 트윈 (USB 시리얼)

웹 카메라로 손 관절을 인식하고(MediaPipe), 각 손가락이 굽은 정도를 서보 각도(0~180°)로 바꿔
USB 시리얼로 ESP32-S3에 보냅니다. 같은 각도가 브라우저 안의 3D 가상 공간(로봇 손 + 서보 5개)에도
그대로 반영되어, 실물과 가상 모델이 함께 움직입니다.

```
웹캠 ─▶ MediaPipe 손 랜드마크(21점) ─▶ 손가락별 굽힘각 ─▶ 보정/스무딩 ─▶ 서보 각도
                                                              ├─▶ 3D 가상 모델 (Three.js)
                                                              └─▶ Web Serial "S,a,b,c,d,e\n" ─▶ ESP32-S3 ─▶ 서보 5개
```

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `firmware/esp32s3_finger_servo/esp32s3_finger_servo.ino` | ESP32-S3 아두이노 스케치 |
| `web/index.html` | 카메라 인식 + 3D 트윈 + 시리얼 전송 웹페이지 (설치 불필요) |
| `start.bat` | 로컬 웹 서버 실행 후 브라우저 열기 |

## 배선

| 손가락 | ESP32-S3 GPIO |
|---|---|
| 엄지 | 4 |
| 검지 | 5 |
| 중지 | 6 |
| 약지 | 7 |
| 새끼 | 15 |

- 서보 신호선(주황/노랑) → 위 GPIO
- 서보 전원(빨강) → **외부 5V 전원** (서보 5개는 최대 수 A까지 흐르므로 보드 5V 핀으로 공급하지 마세요)
- 서보 GND(갈색/검정) → 외부 전원 GND **와 ESP32 GND를 반드시 공통 연결**
- 핀을 바꾸려면 스케치의 `SERVO_PINS`와 웹페이지의 `FINGERS[].gpio`(표시용)를 수정하세요.

## 1. 펌웨어 업로드 (Arduino IDE)

1. 보드 매니저에서 **esp32 by Espressif** 설치 → 보드: **ESP32S3 Dev Module**
2. 추가 라이브러리 불필요 (서보는 내장 LEDC PWM으로 구동)
3. 보드의 **USB(네이티브)** 포트에 연결했다면 `Tools > USB CDC On Boot > Enabled`
   (COM/UART 포트로 연결했다면 그대로)
4. 스케치 업로드 후 시리얼 모니터(115200)에 `READY ...`가 보이면 성공
5. **시리얼 모니터를 닫으세요** — 열려 있으면 웹페이지가 포트를 쓸 수 없습니다.

## 2. 웹페이지 실행

`start.bat`을 더블클릭하면 `http://localhost:8000`이 열립니다. (Python 필요)
**Chrome 또는 Edge**를 사용하세요 (Web Serial 지원).

1. **카메라 시작** → 카메라 권한 허용
2. **ESP32 연결** → 목록에서 ESP32-S3의 COM 포트 선택
3. 손을 쫙 편 상태에서 **① 손 펴고 보정**, 주먹을 쥔 상태에서 **② 주먹 쥐고 보정**
4. 손가락을 움직이면 3D 모델과 실제 서보가 같이 움직입니다.

- **반전**: 서보 장착 방향 때문에 반대로 돌면 해당 손가락의 반전 체크
- **수동 모드**: 카메라 없이 슬라이더로 서보를 직접 테스트
- **스무딩**: 떨림이 심하면 올리고, 반응이 느리면 내리세요
- 보정값과 반전 설정은 브라우저에 저장됩니다.

## 시리얼 프로토콜 (115200 baud)

| PC → ESP32 | 의미 |
|---|---|
| `S,90,45,120,180,0\n` | 엄지~새끼 목표 각도 (0~180) |
| `P\n` | 연결 확인 → `PONG` |
| `C\n` | 모든 서보 90°로 |

ESP32는 1초마다 `ANG,...,RX=초당수신수`로 현재 각도를 보고하며, 웹페이지 로그에 표시됩니다.

## 문제 해결

- **포트 목록에 안 보임**: 데이터 전송 가능한 USB 케이블인지 확인, 시리얼 모니터 닫기
- **서보가 떨리거나 ESP32가 재부팅됨**: 외부 전원 용량 부족 또는 GND 미공통
- **0°/180° 끝에서 끽끽거림**: 스케치의 `PULSE_MIN_US`/`PULSE_MAX_US`를 600/2300 정도로 줄이기
- **손 인식이 불안정**: 밝은 곳에서 손바닥이 카메라를 향하게, 손 전체가 화면에 들어오게
